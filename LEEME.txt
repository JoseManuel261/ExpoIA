INSTRUCCIONES DE INTEGRACIÓN — EXPOIA
========================================

1) Copiar archivos
   Copien el contenido de este paquete DENTRO de su proyecto `expoia` ya
   creado (reemplazando/agregando en `src/`, `public/`, y agregando la
   carpeta `supabase/` y `.env.local.example` en la raíz).

2) Instalar dependencias nuevas
   npm install framer-motion @supabase/supabase-js

3) Variables de entorno
   Copien `.env.local.example` como `.env.local` y llenen:
   - SUPABASE_URL y SUPABASE_SERVICE_ROLE_KEY: Project Settings > API
     dentro de su proyecto de Supabase (org "ExpoIA").
   - CORREO_NOTIFICACIONES y RESEND_API_KEY: pendientes hasta que
     definan el correo oficial y creen la cuenta de Resend.

4) Base de datos
   Entren al SQL Editor de Supabase y ejecuten el contenido de
   `supabase/schema.sql` para crear la tabla `registros_interes`.

5) Correr localmente
   npm run dev
   Abran http://localhost:3000
